# Burnout - Forge Your Godlike Physique

[![Release](https://img.shields.io/github/v/release/gonz-tyler/burnout?label=Version)](https://github.com/gonz-tyler/burnout/releases/latest)
[![Flutter](https://img.shields.io/badge/Flutter-3.x-02569B?logo=flutter)](https://flutter.dev/)
[![Platform](https://img.shields.io/badge/Platform-Android-3DDC84?logo=android)](#)

> **Burnout** is a beautifully crafted, Greek-mythology-themed fitness application built with Flutter. Whether you're training for the Olympics or just starting your journey, this app provides the structure, motivation, and analytics you need to reach Mount Olympus.

---

## Features

*   **Workout Builder:** Create custom routines or choose from pre-made templates inspired by Greek heroes.
*   **Automatic Exercise Progression:** Automatically update weights for future sessions based on exercise difficulty.
*   **Full Body Measurement:** Track your body measurements and view golden ratios.
*   **Muscle Heatmap:** Visualize your gains over time with beautiful, interactive charts.
*   **Offline Support:** Works flawlessly without an internet connection, train anywhere.

---

## For Users: Installation [![Release](https://img.shields.io/github/v/release/gonz-tyler/burnout?label=Version)](https://github.com/gonz-tyler/burnout/releases/latest)

You can install the latest Android release directly on your device.

1. Go to the [Releases Page](https://github.com/gonz-tyler/burnout/releases).
2. Download the latest `app-release-vX.X.X.apk` file.
3. Open the downloaded file on your Android device. 
   *(Note: You may need to enable "Install from unknown sources" in your device settings).*
4. Open the app and start lifting!

## For Developers & Recruiters: Under the Hood

This project was built with an emphasis on clean architecture, and beautiful UI/UX design.

### Tech Stack
*   **Framework:** [Flutter](https://flutter.dev/)
*   **Language:** Dart
*   **Local Storage:** Hive
*   **UI/UX:** Custom theming with a focus on immersive, mythology-inspired aesthetics.

### Architecture Highlights
*   **Clean Architecture:** Separation of concerns between UI, domain, and data layers.
*   **Custom Animations:** Utilized Flutter's animation controllers for smooth, engaging user interactions.
*   **Responsive Design:** Adapts fluidly to different screen sizes and orientations.

### Getting Started (Local Development)

To run this project locally, ensure you have the Flutter SDK installed.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gonz-tyler/burnout.git
   ```
   Navigate to the directory:
   ```bash
   cd burnout
   ```
   Install dependencies:
   ```bash
   flutter pub get
   ```
   Run the app:
   ```bash
   flutter run
   ```
